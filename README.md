# قالب فقط کتاب برای GitHub Pages

قالب استاتیک، فارسی و RTL برای معرفی کتاب‌ها.

## ساختار
هر کتاب در یک پوشه قرار می‌گیرد و `index.html` همان پوشه صفحه کتاب است.

مثال:
`python-for-engineers/index.html`

برای URL کوتاه‌تر مثل:
`https://faghatketab.github.io/python-for-engineers/`

می‌توانید پوشه کتاب را در ریشه Repository قرار دهید و فایل index.html داخل آن باشد.

## اضافه کردن کتاب جدید
1. یکی از پوشه‌های کتاب را کپی کنید.
2. نام پوشه را به slug انگلیسی و کوتاه محصول تغییر دهید.
3. عنوان، توضیحات، مشخصات، لینک خرید و اطلاعات SEO را در index.html تغییر دهید.
4. تصویر جلد را داخل images قرار دهید.
5. sitemap.xml را با URL کتاب جدید به‌روزرسانی کنید.
